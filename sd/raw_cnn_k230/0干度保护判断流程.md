# 0 干度保护和满气报警判断流程

## 1. 0 干度保护判断

### 判断流程

1. 数据从串口进入。
2. 程序连续缓存原始数据。
3. 当前每攒够 `500` 个点，形成一个判断窗口。
4. 窗口形成后，计算下面几个统计值：

| 统计值 | 触发阈值 | 说明 |
| --- | ---: | --- |
| `diff_p95_abs` | `<= 90.0` | 相邻点变化幅度较小 |
| `win_range_mean` | `<= 300.0` | 窗口最大值和最小值差距较小 |
| `win_std_mean` | `<= 55.0` | 窗口整体波动较小 |
| `absz_mean` | `<= 0.022` | 标准化后整体幅值较小 |

5. 对这 4 个统计值做阈值判断。
6. 当前配置要求至少满足 `3` 个条件：

```text
满足条件数量 >= 3
```

### 0 干度最终规则

```text
数据进入
  -> 攒够 500 点窗口
  -> 计算 diff_p95_abs / win_range_mean / win_std_mean / absz_mean
  -> 判断是否至少 3 个统计值满足阈值
  -> 是：触发 0 干度保护，输出 0.0
  -> 否：不触发 0 干度保护，进入神经网络预测，输出模型预测值
```

## 2. 满气报警判断

### 判断流程

满气报警在 0 干度保护之后判断。也就是说，程序先得到本轮干度结果：

- 如果触发 0 干度保护，本轮干度结果为 `0.0`。
- 如果没有触发 0 干度保护，本轮干度结果为神经网络预测值。

然后程序根据连续多轮干度结果和频率变化判断是否满气报警。

| 判断项 | 当前阈值 | 说明 |
| --- | ---: | --- |
| `danger_threshold` | `>= 0.55` | 干度进入偏高区间 |
| `danger_min_count` | `>= 5` | 最近 6 轮中至少 5 轮干度偏高 |
| `alarm_threshold` | `>= 0.60` | 干度达到报警线 |
| `alarm_recent_min_count` | `>= 2` | 最近 3 轮中至少 2 轮达到报警线 |
| `freq_slope_min` | `>= 1.0` | 频率整体呈上升趋势 |
| `freq_rise_min_count` | `>= 4` | 最近 6 轮中至少 4 次频率上升 |

触发满气报警需要同时满足：

```text
最近 6 轮中至少 5 轮干度 >= 0.55
+ 最近 3 轮中至少 2 轮干度 >= 0.60
+ 频率持续上升
+ 本轮没有触发 0 干度保护
```

当前配置还要求报警条件连续满足 `2` 次后，才正式输出满气报警。

### 满气报警最终规则

```text
得到本轮干度结果
  -> 判断最近 6 轮中是否至少 5 轮干度 >= 0.55
  -> 判断最近 3 轮中是否至少 2 轮干度 >= 0.60
  -> 判断频率是否持续上升
  -> 判断本轮是否没有触发 0 干度保护
  -> 判断上面条件是否连续满足 2 次
  -> 是：输出满气报警
  -> 否：不输出满气报警
```

## 3. 解除触发判断

### 判断流程

满气报警已经触发后，程序会继续根据后续多轮干度结果和频率变化判断是否解除报警。

当前主要解除条件如下：

| 判断项 | 当前阈值 | 说明 |
| --- | ---: | --- |
| `mean_off` | `<= 0.54` | 最近 6 轮平均干度下降到解除线以下 |
| `threshold_off` | `<= 0.52` | 最近 6 轮中出现足够多的低干度结果 |
| `min_low_count` | `>= 4` | 最近 6 轮中至少 4 轮干度低于 `0.52` |
| `recent_soft_off` | `<= 0.58` | 最近 3 轮平均干度已经回落 |
| `freq_stop_delta` | `<= 0.0` | 频率不再继续上升 |
| `zero_guard_hit` | `true` | 本轮触发 0 干度保护 |

满足下面任意一种情况，就认为本轮满足解除条件：

```text
最近 6 轮平均干度 <= 0.54
或 最近 6 轮中至少 4 轮干度 <= 0.52
或 最近 3 轮平均干度 <= 0.58 且 频率不再上升
或 本轮触发 0 干度保护
```

当前配置要求解除条件连续满足 `3` 次后，才正式解除满气报警。

### 解除触发最终规则

```text
满气报警已触发
  -> 判断最近 6 轮平均干度是否 <= 0.54
  -> 判断最近 6 轮中是否至少 4 轮干度 <= 0.52
  -> 判断最近 3 轮平均干度是否 <= 0.58 且频率不再上升
  -> 判断本轮是否触发 0 干度保护
  -> 上面任意解除条件连续满足 3 次
  -> 是：解除满气报警
  -> 否：保持满气报警
```
